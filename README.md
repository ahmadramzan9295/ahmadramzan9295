> **Tech Stack:** `PyTorch` • `SAM3` • `Vision Transformers` • `Optimal Transport` • `Computer Vision`

> **Tech Stack:** `Python` • `PyQt6` • `OpenCV` • `Docker` • `Google Cloud Vision OCR` • `PySerial` • `HIDAPI` • `SQLite`
- Built a multi-threaded desktop POS suite interfacing directly with weighing scales and barcode scanners via low-level serial (`pyserial`, `hidapi`, `pyusb`) hardware protocols.

- Containerized the system via Docker with USB/video passthrough and synchronized offline-first SQLite databases with cloud REST API backends.
